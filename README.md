# THUNDER · 雷霆战机

一个零依赖、纯原生 ES Modules + Canvas 2D 的竖版弹幕射击游戏。所有战机、敌机、Boss、子弹、粒子与背景都由代码实时绘制，所有音效与芯片音乐都由 WebAudio 实时合成——**没有任何图片或音频资源文件**，克隆下来起个静态服务就能玩。

```
npm run dev          # 零依赖静态服务器 → http://127.0.0.1:5173/
```

没有 Node 也可以用任意静态服务器：

```
python3 -m http.server 5173
```

> 必须经 HTTP 打开（ES Module 无法在 `file://` 下加载）。

## 操作

| 输入 | 动作 |
| --- | --- |
| `WASD` / 方向键 | 移动 |
| `Shift`（按住） | 精准模式：减速并显示真实判定点 |
| `Space` / `X` / `J` | 释放炸弹（清屏 + 短无敌） |
| `E` / 长按屏幕 | 释放爆发 OVERDRIVE（满能量时） |
| `P` / `Esc` | 暂停 |
| `M` | 静音 / 恢复 |
| `Enter` | 开始 / 重开 |
| 触屏拖动 | 移动（1:1 跟手，手指不遮机体） |
| 触屏双击 | 释放炸弹 |
| 触屏长按 | 释放爆发 |

射击是**全自动**的——只需要专注走位。

## 玩法

- **四种武器流派**（拾取 `W` 循环切换，等级保留）：
  - `PULSE` 均衡连射——任何距离都稳，满级附带激光柱
  - `SPREAD` 广域散射——近身清场，扇形展开
  - `LASER` 持续光束——高 DPS 但必须对准，粉色宽光束
  - `HOMING` 追踪导弹——自动索敌，节奏慢、单发重
- **武器 6 级**：拾取 `P` 升级，中弹掉 1 级。等级对所有流派通用。
- **爆发 OVERDRIVE**：击杀 / 擦弹 / 拾取积累能量（左侧 OD 槽）。满槽后按 `E` 或长按屏幕释放 6 秒——
  敌方时间降到 42%（敌机、敌弹、Boss 全部变慢），玩家射速 ×2、伤害 ×1.35，屏幕进入速度线与蓝色调。
- **擦弹（Graze）**：敌弹从判定点外缘掠过即得能量与分数。这是最高效的充能方式，也是风险与回报的核心博弈。
- **道具**：`P` 武器升级 · `W` 切换流派 · `S` 护盾 · `B` Bomb · `1` 加命。靠近会被磁吸。
- **连击倍率**：连续击坠不受伤最高 ×4.0，中弹即清零。
- **Boss 两形态**：母舰阶段（扇形瞄准 → 双向螺旋 → 环形爆裂）被击破后，核心脱离进入
  `CORE OVERRIDE` 二形态——更小、更快、螺旋 + 环形 + 瞄准穿甲三连同时压上，血条重置。
- **无尽关卡**：击败 Boss 进入下一关，敌人血量/速度/射速逐关提升，BPM 同步加快。

## 演出层（「酷炫」是怎么来的）

- **离屏泛光（Bloom）**：主画面降采样到 1/3 → `brightness/contrast/saturate/blur` 提亮部压暗部 →
  `lighter` 叠回。所有发光体（子弹、核心、爆炸）因此真的在发光，而不是画了一圈假光晕。
- **性能自适应**：连续 90 帧平均帧时 > 28ms 时自动关闭泛光并打印原因；不支持 `ctx.filter` 的浏览器直接降级。
- **镜头**：Boss 转场与爆发会拉远/推近镜头（`Renderer.setZoom`），HUD 不受影响。
- **子弹时间**：只缩放敌方时间，玩家手感不变——这是 OVERDRIVE 的乐趣所在。
- **命中反馈**：顿帧、方向性火星、三层爆炸（火花 / 碎屑 / 烟尘）、冲击波、屏幕震动、闪色。
- **敌弹拖尾**：每颗敌弹带速度方向渐隐尾迹，高速弹幕的轨迹可读性显著提升。

## 项目结构

```
index.html                 舞台 + 三个 DOM 覆盖层（菜单 / 暂停 / 结算）
src/
  main.js                  入口：DOM 接线、主循环、全局按键
  game.js                  编排者：状态机、碰撞、计分、关卡流程、绘制顺序
  config.js                ★ 全部手感参数（速度/伤害/间隔/掉落/难度成长）
  core/
    util.js                数学、随机、对象池、颜色工具
    input.js               键鼠/触摸 → 意图（axes / 边沿动作）
    renderer.js            DPR、逻辑坐标系、震屏、闪色、顿帧
    audio.js               WebAudio 音效合成 + 程序化芯片音乐调度器
  art/
    palette.js             配色语义（冷色=玩家，暖色=敌方，洋红=Boss）
    sprites.js             所有机体的程序化路径绘制 + 光晕/球体缓存
    background.js          三层视差星空、预渲染星云、行星、流星
  entities/
    player.js              自机、武器、僚机、激光、护盾、死亡重生
    bullets.js             玩家弹 / 敌方弹的池化系统
    enemies.js             5 种敌机行为 + Boss 三阶段 AI
    effects.js             粒子 / 冲击波 / 浮动文字 / 道具
  systems/
    spawner.js             关卡波次时间轴（数据驱动编队）
    hud.js                 分数、生命、炸弹、武器、Boss 血条、横幅
tools/
  serve.mjs                零依赖静态服务器
  check.mjs                静态门禁：语法 / 导入路径 / 属性遮蔽
```

### 几个刻意的设计决定

- **小判定**：玩家判定半径 3.6px，机体视觉约 36×44。这是弹幕射击"擦弹"手感的来源。
- **瞬时移动**：没有惯性。精确操控优先于物理真实。
- **子步长循环**：每帧把 dt 切成不超过 1/60 的小步推进，高刷屏不重复帧，低端机不跳步。
- **绘制顺序固定**：背景 → 激光 → 尾迹 → 敌人 → Boss → 玩家 → 子弹 → 粒子 → 道具 → 文字 → HUD → 屏幕特效。
- **性能**：子弹与光晕全部走离屏缓存精灵，粒子上限 900，敌人数组交换删除，无逐帧渐变分配（除少量 UI）。

## 开发命令

```
npm run check     # 静态门禁（零依赖）：语法 + 导入路径 + 属性遮蔽检查
npm run dev       # 本地服务
```

`check.mjs` 的「属性遮蔽」规则来自两个真实缺陷：`HUD.banner` 与 `Renderer.hitStop` 都是实例属性与原型方法同名，构造函数的一次赋值把方法静默覆盖成了值。这类错误在动态语言里不会报类型错，只会在调用时炸——所以把它做成自动检查。

### 调参入口

几乎所有手感相关数值都在 `src/config.js`：玩家速度、判定半径、武器间隔与伤害、敌人 HP/速度/射速、掉落权重、Boss 血量与阶段阈值、关卡难度成长曲线。改完刷新即可，无需构建。

## 已知边界

- 音频在首次用户手势后初始化（浏览器自动播放策略）。点任意键或按钮即可出声。
- 无存档关卡进度，只持久化最高分（`localStorage`）。
- 触屏以 `pointer` 事件统一处理，支持鼠标拖动；未在真机 iOS/Android 上做帧率与手感标定。
